# 👋 欢迎使用 LiMo

> 你好，欢迎来到 **LiMo** —— 一款把「任意内容」变成「结构化知识」的本地知识管理工具。
> 这是「笔记」页，用一分钟了解 LiMo 能做什么；想看更深入的技术细节，请切换到「整理版原文」页。

## 一分钟了解 LiMo

LiMo 帮你把 **URL / 文本 / 文件**（PDF、Word、PPT、Excel、EPUB、图片、视频）自动变成 **结构清晰的笔记**：

| 输入 | 你会得到 |
|------|---------|
| 网页链接 | 正文提炼 + 结构化笔记 |
| PDF / Word / PPT / Excel / EPUB | 全文转文字 + 智能笔记 |
| 图片 | 文字提取、表格数字化、AI 理解 |
| 视频 | 语音转文字 + 可选的画面理解 |
| 任意文本 | 粘贴即整理 |

## 核心功能

1. **导入** —— 粘贴链接，或把文件直接拖进来
2. **生成** —— 一键产出「笔记」和「整理版原文」两种风格；每次生成都存一版，历史版本全部保留，随时切回
3. **整理** —— 文件夹可以嵌套，标签、全文搜索、日期筛选都支持；选中一批文档还能让 AI 建议怎么分门别类
4. **多篇合成** —— 勾选两篇以上，让 AI 写一份跨文档的对比综述
5. **图片处理** —— 提取图中文字 / 表格数字化 / AI 理解
6. **AI 对话** —— 基于你的文档提问，支持联网搜索
7. **导出** —— Markdown / 自包含 HTML / Word / PDF / ZIP，随时带走

## 开始使用

- 把网页链接或文件拖进左侧导入区，点「导入」
- 导入完成后点「生成」，几秒后你会看到两份产物：
  - **笔记**：提炼重点，方便回顾
  - **整理版原文**：忠实整理的原文
- 生成前还可以顺手勾选几项：**图表**（把关系画成图）、**追问建议**（读完自然会问的几个问题，点一下直接带进 AI 对话）、**联网检索**（给笔记补一份外部参考料）
- 导入的东西都在左侧**文档库**里：建文件夹、打标签、全文搜索（`Ctrl+K`）、按类型和日期筛；选中一批文档可以批量移动 / 打标签 / 删除，也可以让 AI 建议分类
- 右上角「设置」里可以配置大模型和转换引擎

> 💡 提示：文档生成时，还可以勾选「保留文档图片 / OCR 提取图中文字 / AI 分析图片」——三个开关互相独立，任意组合。

## 关于 LiMo 的名字与理念

**LiMo（沥墨）—— 我们不生产知识，只做知识的「转换」与「过滤」。**

「沥」是过滤，把纷杂的内容滤去杂质、滴出精华；「墨」是文字，把不同形态的内容沉淀成文字。LiMo 只做三件事：

- **转换**：把视频、PDF、图片、网页等不同形态的内容，转成统一、可读的文字
- **过滤**：去除噪音、提炼要点、按你的需求整理成结构化的笔记
- **呈现**：让整理好的知识便于回顾、分享和带走

**真正的知识，来自每一位原创内容生产者。** 无论是一篇文章、一条视频还是一本书，都凝结着创作者的心血。**向每一位知识生产者致敬。** 🙏

## 常见问题

**Q: LiMo 需要付费吗？**

A: LiMo 本身是免费软件。用大模型生成内容需要你自己的 API Key（DeepSeek 等，很便宜），也可以接入本地模型（如 Ollama）实现零成本。

**Q: 我的数据安全吗？**

A: 数据默认保存在你的电脑本地（`~/.limo`），API Key 脱敏存储，不会强制上传你的资料。

**Q: 支持哪些文件格式？**

A: 网页链接、PDF、Word、PPT、Excel、EPUB、图片、视频，以及任意文本。

**Q: 没有大模型 Key 能不能用？**

A: 可以。文档解析、视频转写（bcut-asr 免费云转写）开箱即用；生成笔记 / 整理 / 对话 / 多篇合成需要配置一个大模型。图片文字识别需要 DashScope 的 Key（本地 OCR 引擎已改为可选插件）。

**Q: 视频转写花钱吗？**

A: 默认的 bcut-asr 免费云转写无需 Key；本地转写引擎（faster-whisper 等）需自行安装。

**Q: 可以离线使用吗？**

A: 文档解析在本机完成，断网也能用；视频转写、云端大模型、联网搜索需要联网。语义检索如果选本地模型，这一部分也不出本机。
