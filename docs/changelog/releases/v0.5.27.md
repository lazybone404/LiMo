# v0.5.27

发布日期：2026-11-13　｜　范围：`v0.5.25..HEAD`

文档较多的库打开更快，生成面板更紧凑；折叠阅读补上了一键全部展开，每份产物顶部能看到这一版花了多少 token 和多少钱。

## 阅读

- 主题档与一句话档可以一键全部展开或全部收起，按钮在内容区顶部、原链接左侧。
- 每份生成的产物顶部多一枚用量标签，显示这次生成用了多少 token、花的钱（模型配了价格才显示金额）。

## 生成

- 笔记风格新增「平实」档：正文直接说事，不写「值得关注」「意义重大」这类空话。
- 笔记格式、生成产物、思考强度、AI 画面理解这几组选项的字号与间距缩小，一屏能看全。

## 文档库

- 每行前面的复选框去掉了，选中改用 Ctrl / Cmd 点击，Shift 点击连选一段。

## 启动与更新

- 文档多的库启动时不再逐个重扫，打开明显更快。
- 用 MSI 安装的用户点更新后拿到的是 MSI 版，不会再被换成 NSIS 版。
- 覆盖安装时先关掉后台进程，安装器不会因为文件被占用而中途失败。
