# v0.5.32

发布日期：2026-11-24　｜　范围：`v0.5.31..HEAD`

对话里的联网设置合成一个三选一；长文档提问不再只读到开头，AI 能按节或按位置接着往下读。

## 对话

- 联网设置从两个开关合成一个三选一：关闭 / 本地检索 / 服务端检索。原来「联网」与「深度联网」能组合出「关了联网却开着深度联网」这种没有意义的状态。
- 长文档装不下时，不再只把开头交给 AI：会带上目录与和这个问题相关的几段，它还能按节标题或按位置继续往下读。模型因此知道自己看的是节选，不会再把「没看到后面」说成「原文没提到」。
- 交给 AI 的是你正在看的那一份：在笔记、整理版原文、转录之间切换，它读到的就跟着换。
- 你配的搜索方案没生效、退到备用方案时，回答里会说明这件事，而不是默默换一家继续答。

## 任务

- 到并发上限后任务进入队列，任务面板里能看到「排队中」，也能取消。此前只弹一条提示，收起面板再打开就什么也看不到。
- 排队中的任务不会被重复提交成两个；轮到它开始时，也不会把你正在读的另一篇切走。

## 修复

- 服务端检索时，界面不再先显示一次实际没有发生的「搜索」。第一次动作是读网页时，气泡从现在开始直接显示「抓取」。
- 排队任务出队后，不再清空另一篇文档的正文。
