# v0.5.23

发布日期：2026-11-08　｜　范围：`v0.5.21..HEAD`

安装版现在可以自己更新了。另外，导入和转录拆成了两步，批量任务可以在后台排队跑完。

## 应用内更新（仅安装版）

- **设置 → 通用 → 应用更新**，可以检查并安装新版本，装完自动重启。
- 启动约 20 秒后自动查一次，之后每 24 小时一次。有新版本会弹提示，不想升某个版本可以「跳过此版本」。
- 直连不通时自动改走镜像，下载中会说明当前是否在走中转。
- 还有任务在跑时，安装按钮会禁用并说明原因 —— 安装会让应用退出，正在跑的生成和转录会断在半路。

## 导入与转录分开

- 导入视频 / 音频默认**只收纳、不转录**，需要时再点转录。文档和网页仍是一键导入即处理。
- 新增批量队列：一次选多篇做导入、转录或生成，关掉面板也会继续，重新打开能看到进度。
- 还没转录的篇不进搜索索引，也不会被拿去生成。

## 折叠阅读

- 产物可以按「主题 / 一句话 / 全文」三档折叠，切换改成带文字的滑块。
- 只有标题的节显示成一条分隔线；只有一句话的节不再给展开按钮。

## 文档库

- 可以按正文状态（已转录 / 待转录 / 无正文）筛选。
- 「未分类」可以整组勾选。
- 智能分类选「只打标签」时，不再把文档从原来的文件夹里挪出去。

## 导出

- 导出的 Word 文档带上产物来源属性；合成产物在自证条里列出参考过的文档。
- 导出 ZIP 时图片会自动缩小。
- 纯文本导出不再带那一行自证头。

## 界面

- 顶部的三条栏和左侧栏位收窄了一些，内容区更宽。
- 提示词下拉里能看到版本号与内容指纹，改过提示词时能看出哪一份变了。

## 修复

- 批量队列结束时如果某一步出错，对话框不再永远停在「运行中」。
- 转录完成后正文回填不再因为切换页面而丢失。
- 「自动转录」关掉之后真的不会再自动转录。
- 合成时不再把还没转录的篇算进去。
