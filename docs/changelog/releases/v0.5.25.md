# v0.5.25

发布日期：2026-11-10　｜　范围：`v0.5.24..HEAD`

合成、插件依赖安装、电子书解读这三类要跑一阵子的操作，现在都交给后台任务队列：切走、收起面板、关掉窗口再打开，它们照常推进，进度在顶栏的任务面板里。

## 后台任务

- 顶栏的任务面板统一列出这些任务，显示进度和当前在做什么，想停在那里点取消。
- 合成：切到别的文档、把文档库收起来都不打断它；同一批文档、同样的原料与读者意图再点一次，会接回还在跑的那一次，不重复花钱。
- 合成万一进程中断，这条任务会标成失败并写明「进程中断」，不会自作主张再跑一遍。
- 插件依赖安装同样如此：关掉设置页不影响安装，回到设置页能看到结果。

## 电子书解读

- 折叠面板、切到别的文档都不再打断解读；已解读的章节会保留，回来点「继续上次解读」接着跑。
- 解读完成时如果正开着这本书，预览区会直接换成新的笔记与整理版。

## 应用更新

- 下载与安装拆成两步：先下载并验签，下完由你决定什么时候重启安装。
- 下载途中刷新页面或切走，回来进度还在。

## 生成面板

- 风格档位改成可折叠的小胶囊，平时不占地方，点开再选。
