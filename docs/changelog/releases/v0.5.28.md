# v0.5.28

发布日期：2026-11-14　｜　范围：`v0.5.25..HEAD`

对话多了一个「深度联网」开关，联网检索交给 DeepSeek 在服务端完成，回答带回可点来源；大 PDF 不再受 14MB 限制，扫描件识别与语音转写也能绑到 DeepSeek。

## DeepSeek

- 对话框「允许联网」旁多一个「深度联网」按钮：开启后检索与读网页在 DeepSeek 服务端完成，回答附来源，可点开原文。
- 这个按钮只在对话模型是 DeepSeek 的对应模型时出现。
- 开启的这一轮用不了知识库的三个工具（搜索文档、查文档、列文档）；用 @ 引用的文档仍然照常带上。
- 第一轮会给会话起一个短标题；自己改过标题的不会被覆盖。
- 用 DeepSeek 对话模型生成笔记时，超过 14MB 的 PDF 改为直传原件，上限提到 100MB；同一份文件第二次生成不再重复上传。
- 设置 → 引擎里可以给扫描件识别与语音转写绑定 DeepSeek。
- 设置页不再明文显示 DeepSeek 联网用的 Key。

## 阅读

- 折叠阅读可以一键全部展开或全部收起，按钮在内容区顶部。
- 每份生成的产物顶部多一枚用量标签，显示这一版用了多少 token、花了多少费用。

## 生成

- 笔记风格新增「平实」档：正文直接说事，不写「值得关注」「意义重大」这类空话。
- 生成面板里几组选项的字号与间距缩小，一屏能看全。

## 文档库

- 每行前面的复选框去掉了，选中改用 Ctrl / Cmd 点击，Shift 点击连选一段。

## 启动与更新

- 文档多的库启动时不再逐个重扫，打开明显更快。
- 用 MSI 安装的用户点更新后拿到的是 MSI 版，不会再被换成 NSIS 版。
- 覆盖安装前会先关掉后台进程，安装器不会因为文件被占用而中途失败。
- NSIS 安装包改为需要管理员权限，装在 Program Files 下升级时不再报文件写入失败。
