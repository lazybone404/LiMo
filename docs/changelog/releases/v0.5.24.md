# v0.5.24

发布日期：2026-11-08　｜　范围：`v0.5.23..HEAD`

阅读版式多了一组一键预设；产物在别处被改过之后，再在 LiMo 里保存不会再悄悄冲掉那次改动。

## 阅读版式预设

- 设置 → 阅读版式里多了「随应用 / 书页 / 紧凑」三组预设，一次设好行高、每行字数与段落区隔。
- 「书页」是首行缩进、行距放宽、每行约 34 字的中文出版物排法；「紧凑」行距最窄，同样高度能看到更多行。
- 预设只动排版，不动字号；三个旋钮单独微调之后，标题旁会标「自定义」。

## 编辑保存

- 如果这一版产物文件在你编辑期间被别的程序改过，保存时会提示而不是直接覆盖，可以选「用我的覆盖」。
- 带 BOM 或 Windows 换行的产物文件，正文与「已编辑」标记都能正常读出，不再出现标记丢失。

## 修复

- 插件偶尔往控制台打一行调试信息，不会再导致它被判定中断。
